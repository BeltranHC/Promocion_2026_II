## 📖 **Descripción**

<div align="center">

> *"La tecnología al servicio de nuestra promoción"*

</div>

Plataforma web **full-stack** desarrollada para la gestión integral de la **Promoción 2026** de la Escuela Profesional de Ingeniería Estadística e Informática (EPIEI) de la Universidad Nacional del Altiplano - Puno.

### 🎯 **Objetivo**
Centralizar la administración de eventos, aportes económicos, galería de fotos y comunicación entre los miembros de la promoción en una única plataforma moderna y escalable.

### 🛡️ **Funcionalidades del Sistema**

```
✅ Autenticación JWT con cookies HTTP-only
✅ Panel de administración completo
✅ CRUD de estudiantes, eventos y contribuidores
✅ Sistema de pagos y aportes semanales
✅ Gestión de galería con Cloudinary
✅ Venta de tickets para eventos
✅ API RESTful con Next.js App Router
✅ Base de datos PostgreSQL con Prisma ORM
✅ Diseño responsive con TailwindCSS
✅ Animaciones fluidas con Framer Motion
```

## 🏃‍♂️ **Inicio Rápido**

### 📋 Prerrequisitos

```bash
node >= 18.0.0
npm >= 9.0.0
PostgreSQL >= 15
```

### 🔧 Instalación

<details>
<summary><b>📥 Paso 1: Clonar e instalar dependencias</b></summary>

```bash
# Clonar el repositorio
git clone https://github.com/junidev/promocion2026.git

# Navegar al directorio
cd promocion2026

# Instalar dependencias
npm install
```

</details>

<details>
<summary><b>⚙️ Paso 2: Configurar variables de entorno</b></summary>

```bash
# Crear archivo de variables de entorno
cp .env.example .env
```

Editar `.env` con tus credenciales:

```env
# Base de datos PostgreSQL
DATABASE_URL="postgresql://usuario:contraseña@localhost:5433/promo_2026?schema=public"

# JWT Secret para autenticación
JWT_SECRET="tu-secret-key-segura"

# Cloudinary (para galería de fotos)
CLOUDINARY_CLOUD_NAME="tu-cloud-name"
CLOUDINARY_API_KEY="tu-api-key"
CLOUDINARY_API_SECRET="tu-api-secret"
```

</details>

<details>
<summary><b>🗄️ Paso 3: Configurar base de datos</b></summary>

```bash
# Ejecutar migraciones
npm run db:migrate

# (Opcional) Poblar con datos de prueba
npm run db:seed
```

</details>

### 🚀 Ejecutar

```bash
# Modo desarrollo
npm run dev

# Construir para producción
npm run build

# Iniciar servidor de producción
npm start
```

<div align="center">

🌐 Abre [http://localhost:3000](http://localhost:3000) en tu navegador

</div>
